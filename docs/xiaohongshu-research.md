| 版本与环境 | 当时观察到的结果 |
| --- | --- |
| 0.11.0，临时 Web 宿主、专用账号 | 重启宿主后连续取得 34 和 25 个不同编号，两批无交集。从第二批打开图文笔记后成功解码第 2 张图片并读取评论。视频可播放和拖动进度。两次收起预览后，原行位置误差均为 0 CSS px。 |

## 数据与账号

- 同次导航的首页 HTML、`homefeed` 响应和已渲染卡片都可提供首批数据。首页文档响应体被浏览器回收时，页面上仍可能有可读条目。空批次也可能先于卡片到达。已连接账号遇到登录页或失效会话时，显示重新扫码提示。[首页读取](../src/sites/xhs/home.js) · [首批与刷新回归](../test/excerpt-home.test.js)
- 官网页面会回收滚出视口的卡片。打开旧条目时，使用原卡给出的完整链接，在同一账号的浏览器上下文中核对笔记 ID。对删除、限流、登录失效和访问受限分别处理。签名链接、推荐内容和账号上下文不写入公开缓存。[官网会话](../src/sites/xhs/browser.js) · [单篇归属与错误](../src/sites/xhs/detail.js)
- 详情的图序以官网返回的顺序为准，轮播的重复节点需剔除。图片和视频在 DSH 端通过同源附件路由按需加载，视频拖动使用 HTTP Range。换号后先前笔记的媒体授权失效。[媒体路由](../src/sites/xhs/media.js) · [账号隔离测试](../test/excerpts.test.js)

## 为什么保留文字索引

研究时对比过右栏画廊和主区大图。右栏能保留首页的阅读位置，主区大图虽给竖图留出更多空间，却需要离开索引再返回。最终采用主区文字索引、右栏正文与折叠附件。用户点开附件才加载一张图片或一个静音视频，合上右栏后按原笔记编号和点击时的行偏移恢复焦点。[最终界面示意](excerpt-workspace.png) · [阅读状态](../src/client/excerpt-store.js)

## 复验

1. 在临时 `DSH_HOME` 安装待测包，用游客会话打开「资料摘录 → 阅读索引」。记录首批条数和错误类型。刷新会建立新首页，滚动才是续批。
2. 有专用测试账号时，从输入栏「＋」连接来源。续读一批，比较前后两批编号的交集，然后从第二批打开图文和视频，核对正文归属、图片顺序、视频拖动和可见评论。只记录批次数量、响应状态和位置误差。
3. 在 1440、768、767 px 窗宽测试附件展开前的请求数、失焦后收起、Esc 还位和继续滚动。将临时 Web 宿主的回环启动地址通过进程环境变量 `EXCERPT_TEST_URL` 传入。地址含有宿主令牌，避免写入文件或终端输出。[虚构条目界面验收](../scripts/check-excerpts.mjs) · [专用账号实机验收](../scripts/check-excerpts-live.mjs)
